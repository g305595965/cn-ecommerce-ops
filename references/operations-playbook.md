# 日常运营、数据体系与风控手册

---

## 一、GMV 公式拆解：所有运营动作的起点

```
GMV = 曝光量 × 点击率 × 转化率 × 客单价
    = 访客数(UV) × 转化率 × 客单价
    = 访客数 × UV 价值
```

**任何提升 GMV 的动作，必然落在这四个变量之一上。**
说不清自己在优化哪个变量的运营动作，都是无效动作。

| 变量 | 提升手段 | 见 |
|------|---------|-----|
| 曝光量 | 关键词覆盖、付费投放、活动坑位、内容分发 | platform-playbook.md |
| 点击率 | 主图、标题、价格带、人群精准度 | listing-and-content.md |
| 转化率 | 详情页、评价、价格力、信任状、客服 | listing-and-content.md |
| 客单价 | 套餐搭配、满减凑单、关联推荐、升级款 | 本文第四节 |

**诊断顺序**：先用 `scripts/diagnose.py` 找出最短板的环节，
再针对性投入。四个变量都及格时，才应该加大流量投入。

## 二、核心指标定义与健康区间

### 流量与转化
| 指标 | 计算方式 | 说明 |
|------|---------|------|
| UV | 独立访客数 | 流量规模 |
| 点击率 CTR | 点击 ÷ 曝光 | 主图与标题的吸引力 |
| 转化率 CVR | 支付人数 ÷ 访客数 | 承接能力 |
| UV 价值 | 支付金额 ÷ 访客数 | 单个流量的产值，投放的核心依据 |
| 客单价 | 支付金额 ÷ 支付人数 | 单笔订单规模 |
| 加购收藏率 | 加购收藏 ÷ 访客 | 潜在需求，预示后续转化 |

### 投放效率
| 指标 | 计算方式 | 说明 |
|------|---------|------|
| ROI / ROAS | 成交金额 ÷ 广告花费 | 投产比 |
| 保本 ROI | 1 ÷ 毛利率 | 低于此值必亏，用 `ad_calc.py` 算 |
| CPC | 花费 ÷ 点击 | 点击单价 |
| CPA | 花费 ÷ 成交单数 | 获客成本 |
| GPM | 成交额 ÷ 曝光 × 1000 | 抖音核心指标 |

### 服务与健康度
| 指标 | 健康区间（经验值） | 影响 |
|------|-----------------|------|
| DSR 动态评分 | ≥ 4.8 | 低于均值影响搜索权重 |
| 退款率 | 低于行业均值 | 超标直接降权 |
| 退款自主完结时长 | 越短越好 | 影响服务分 |
| 发货时效 | 24–48 小时内 | 超时罚款且降权 |
| 客服响应时长 | < 30 秒 | 影响转化与服务分 |
| 纠纷率 | 越低越好 | 严重时限制活动报名 |

**重要**：各平台的服务分（抖音体验分、拼多多服务分、天猫 DSR）
直接决定能否报名活动、能否获得流量扶持，是运营的生命线。

## 三、运营节奏

### 每日必做（30 分钟）
1. 看昨日核心数据：GMV、UV、转化率、ROI，与前一日/上周同期对比
2. 检查异常：流量突降、转化突降、差评、退款激增
3. 处理待发货订单，确保不超时
4. 回复所有评价与「问大家」
5. 检查广告计划消耗与 ROI，暂停明显亏损的计划

### 每周必做
1. 拉取周数据，做转化漏斗诊断（`diagnose.py`）
2. 关键词报表分析：加词、删词、调价
3. 竞品监控：价格、活动、新品、主图变化
4. 库存盘点，触发补货
5. 复盘本周投放，输出下周计划

### 每月必做
1. 全店产品结构复盘：引流/利润/形象/狙击款的贡献占比
2. 利润核算（`pricing.py` 实算，不看毛估）
3. 差评关键词聚类，输出产品改进需求
4. 下月活动排期与备货计划

## 四、提升客单价的六种手段

1. **满减凑单** —— 门槛设在客单价的 1.5 倍左右最有效
2. **套餐组合** —— 主品 + 配件打包，比单卖利润更高
3. **多规格阶梯定价** —— 买 2 件更划算，直接拉高件单价
4. **关联推荐** —— 详情页底部与购物车页推荐互补品
5. **升级款引导** —— 用价格锚点让中间档看起来最划算
6. **赠品换购** —— 加 X 元换购高感知价值商品

**注意**：提升客单价往往会降低转化率，
需用 `ad_calc.py` 验证 UV 价值（客单价 × 转化率）是否净提升。

## 五、大促节奏（以双 11 / 618 为例）

| 阶段 | 时间 | 核心动作 |
|------|------|---------|
| 预热蓄水 | 提前 30–45 天 | 上新、内容种草、拉新加购收藏 |
| 加购蓄水 | 提前 10–15 天 | 定金预售、优惠券发放、直播预告 |
| 爆发期 | 大促当日 | 全力投放、直播续场、客服全员待命 |
| 返场期 | 后 3–7 天 | 承接犹豫用户，清理尾货 |
| 复盘期 | 后 7–15 天 | 数据复盘、退货处理、库存消化 |

**易踩的坑**：
- **备货不足**：爆单后断货，权重与口碑双杀
- **备货过量**：大促后长期库存积压，现金流枯竭
- **价格穿底**：为冲量把价格打到亏损，大促后无法恢复原价
- **客服崩盘**：响应超时导致服务分下降，影响后续流量
- **物流爆仓**：预留发货缓冲，提前与快递协商产能

## 六、售后与客服

### 降低退货率的实操手段
1. **前置预期管理** —— 详情页把尺码、色差、材质说清楚，
   宁可少卖也不要卖错。预期落差是退货第一原因。
2. **尺码表要给真实数据** —— 服饰类提供模特身高体重与穿着尺码
3. **主动售后** —— 发货后主动推送物流，签收后回访
4. **退货原因分析** —— 每月聚类分析，反推产品与文案问题

### 差评处理原则
- **第一时间响应**，24 小时内
- 公开回复是**写给潜在买家看的**，不是写给差评者看的：
  克制、专业、给出解决方案，不辩解不对骂
- 私下联系解决实际问题，能挽回则挽回
- **不得删除或屏蔽真实差评**，也不得骚扰要求修改评价

## 七、风控红线（触碰即重罚）

### 平台层面
| 违规行为 | 后果 |
|---------|------|
| 刷单炒信 | 扣分、降权、清退，情节严重构成犯罪 |
| 虚假发货 | 高额罚款 + 降权 |
| 延迟发货 | 按单赔付 + 服务分下降 |
| 售假/侵权 | 商品下架、扣分、店铺关闭、保证金扣除 |
| 盗用他人图片 | 侵权投诉、删除链接、赔偿 |
| 描述不符 | 退款率上升 + 平台处罚 |
| 站外引流 | 小红书/抖音尤其严格，限流至封号 |
| 好评返现 | 违规且涉嫌违反《反不正当竞争法》 |

### 法律层面
- **《广告法》第九条** —— 绝对化用语，罚款起点二十万元。
  所有文案发布前必须过 `scripts/compliance.py`。
- **《消费者权益保护法》** —— 七天无理由退货义务
- **《电子商务法》** —— 平台内经营者需公示营业执照、依法纳税
- **《反不正当竞争法》** —— 禁止虚假宣传、刷单、诋毁竞争对手
- **《价格法》** —— 禁止虚构原价、虚假优惠折价

### 自查频率建议
- 每次上新：合规扫描 + 资质核对
- 每周：抽查在售商品文案
- 每月：全店文案批量扫描（`compliance.py --file`）
- 平台规则更新时：立即全店自查

## 八、常见问题速查

**Q：流量突然下降怎么办？**
按顺序排查：① 是否有违规扣分 ② 关键词排名是否掉了
③ 竞品是否有大动作 ④ 是否是类目大盘下滑（看行业数据）
⑤ 主图/标题/价格是否被改动 ⑥ 广告计划是否被暂停或预算耗尽。

**Q：有流量没转化？**
用 `diagnose.py` 定位具体环节。常见原因：流量不精准（人群标签乱了）、
价格无竞争力、评价有硬伤、详情页说服力不足。

**Q：ROI 一直做不上去？**
用 `ad_calc.py` 先算保本 ROI。若当前 ROI 低于保本值，
优先级是：提转化率 > 降 CPC > 提客单价。
盲目加预算只会放大亏损。

**Q：要不要做低价冲量？**
先算账。低价冲量会打乱人群标签、拉低客单价心智，
且平台比价机制会记录历史低价。除非有明确的冲层级/冲活动目标，
否则不建议。用 `pricing.py` 算出保本售价，绝不低于此价。
