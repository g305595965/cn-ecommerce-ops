## 一、标题优化

### 各平台字数限制
| 平台 | 上限 | 备注 |
|------|------|------|
| 淘宝 / 天猫 | 30 汉字（60 字符） | 用满，不浪费字符 |
| 京东 | 30 汉字左右 | 品牌词前置 |
| 拼多多 | 60 字符 | 简洁直白，突出价格力 |
| 抖音商城 | 30 汉字左右 | 口语化，贴近搜索习惯 |
| 小红书笔记 | 20 汉字（显示约 20 字） | 前 10 字最关键 |

### 标题结构公式
```
营销词 + 品牌词 + 核心词 + 属性词 + 场景词 + 长尾词
```

**示例**（女士针织衫）：
```
2024新款 XX品牌 针织开衫 女 宽松 慵懒风 春秋 外搭 小个子 上衣
```

### 关键原则
1. **核心词必须完整可切分** —— 不要把"针织开衫"拆成"针织 时尚 开衫"，
   否则搜索引擎无法完整匹配"针织开衫"这个词。
2. **新品用长尾词，成熟品抢大词** —— 新品没有权重，抢大词只会被淹没。
   先用"针织开衫女小个子慵懒风"这类精准长尾词吃转化。
3. **属性词必须与后台属性一致** —— 不一致会被判定为标题违规或降权。
4. **不堆砌无关热词** —— 引来不精准流量会打乱人群标签，得不偿失。
5. **禁用广告法违禁词** —— "最"字系、"第一"、"国家级"等一律不能出现。

### 关键词来源
- 平台搜索下拉框（真实用户搜索）
- 竞品标题拆解（取交集高频词）
- 生意参谋 / 抖音电商罗盘 / 京东商智的搜索词分析
- 直通车关键词报表（有真实点击数据的词最可靠）

## 二、主图设计（决定点击率）

### 五图 + 一视频的标准配置
| 位置 | 作用 | 要点 |
|------|------|------|
| 主图 1 | 抓眼球 | 产品主体清晰 + 一句核心卖点（≤8字） |
| 主图 2 | 卖点强化 | 最强差异化功能，用对比或数据体现 |
| 主图 3 | 场景化 | 产品在真实使用场景中的样子 |
| 主图 4 | 细节特写 | 材质、工艺、做工，建立品质感 |
| 主图 5 | 信任状 | 资质证书、检测报告、售后承诺 |
| 主图视频 | 综合展示 | 15–30 秒，前 3 秒必须有信息量 |

### 提升点击率的实操要点
- **左上角是黄金视觉区**，最重要的信息放这里（符合 F 型视觉动线）
- 文字**不超过图片面积 20%**（平台规则），且必须大而清晰，
  手机上缩略图只有指甲盖大小，小字等于没有
- **色彩要跳出搜索结果页**：竞品都用白底，你用彩底就能跳出来
- **主图必须 A/B 测试**，用直通车小预算测点击率，
  跑出高于行业均值的图再放大投放，不要凭审美决定

## 三、详情页黄金结构

用户决策路径：**我有什么问题 → 你能解决吗 → 凭什么信你 → 为什么现在买**

| 屏序 | 内容 | 目的 |
|------|------|------|
| 第 1 屏 | 核心卖点 + 使用场景大图 | 3 秒内说清"这是什么、解决什么" |
| 第 2 屏 | 痛点场景还原 | 引发共鸣："这说的就是我" |
| 第 3 屏 | 解决方案 + 核心功能 | 给出答案 |
| 第 4 屏 | 参数与规格 | 满足理性决策需求 |
| 第 5 屏 | 细节展示 | 材质、做工、工艺 |
| 第 6 屏 | 信任背书 | 资质、检测报告、销量、媒体报道 |
| 第 7 屏 | 用户评价 / 买家秀 | 从众心理，真实感最重要 |
| 第 8 屏 | 售后保障 | 消除最后顾虑（七天无理由、运费险、质保） |
| 第 9 屏 | 促销信息 + 行动号召 | 临门一脚，制造合理紧迫感 |

**核心原则**：
- **前三屏决定 70% 的跳失**，最强的内容必须前置
- 移动端优先，单张图高度不超过 1200px，避免加载过慢
- **不要用大段文字**，用图 + 短句，用户是"扫"不是"读"
- 促销紧迫感必须**真实**（虚构倒计时构成价格欺诈）

## 四、短视频带货脚本框架

### 黄金 3 秒开场（决定生死）
四种经过验证的开场方式：
1. **痛点直击** —— "你是不是也这样..."
2. **结果前置** —— 直接展示使用后的效果
3. **反常识冲突** —— "千万别再这样做了"
4. **身份代入** —— "小个子女生一定要看"

### 30–60 秒脚本结构
```
0–3s   黄金开场（痛点/结果/冲突）
3–10s  问题放大（为什么这件事很麻烦）
10–25s 产品出场 + 核心卖点演示（要看得见的效果）
25–40s 使用场景 + 效果展示
40–50s 信任背书（销量/资质/真实反馈）
50–60s 行动号召 + 利益点（限时优惠、赠品）
```

### 关键指标与优化方向
| 指标不达标 | 优化位置 |
|-----------|---------|
| 3 秒完播率低 | 开场没抓住人，重做前 3 秒 |
| 完播率低 | 中段节奏拖沓，删冗余镜头 |
| 点击率低 | 挂车时机不对，或产品与内容不匹配 |
| 转化率低 | 落地页承接问题，看详情页与价格 |

## 五、直播运营

### 单场直播节奏（15–25 分钟一个循环）
```
1. 引流憋单（3–5 分钟）
   用福利款/秒杀留人，拉停留时长，积累在线人数
2. 产品讲解（8–12 分钟）
   痛点 → 卖点 → 演示 → 对比 → 信任状
3. 逼单成交（3–5 分钟）
   限时限量、价格锚点、赠品叠加，倒数上链接
4. 循环往复
```

### 货盘结构
- **福利款** —— 引流留人，亏本或平本，控制数量
- **爆款/主推款** —— 走量核心，占销售额 50% 以上
- **利润款** —— 赚钱主力
- **形象款** —— 拉高客单价与直播间调性

### 核心指标诊断
| 指标 | 说明 | 偏低时的动作 |
|------|------|------------|
| 平均停留时长 | 低于 30 秒说明开场有问题 | 改开场话术、加福利钩子 |
| UV 价值 | 成交额 ÷ 观看人数 | 提高转化或客单价 |
| 转化率 | 成交人数 ÷ 观看人数 | 优化讲解与逼单话术 |
| 互动率 | 评论点赞 ÷ 观看 | 增加互动引导与抽奖 |

## 六、评价与口碑运营

评价是转化率的**决定性因素之一**，尤其是前 10 条。

### 实操要点
- **首批评价至关重要**，必须确保真实优质，带图带视频
- 主动引导评价：包裹卡（不得以好评返现诱导，平台明令禁止）、
  售后回访、会员积分
- **差评必须第一时间响应**，公开回复要克制专业，
  展现解决问题的态度——回复是给后来的潜在买家看的
- **定期分析差评关键词**，这是产品迭代最真实的输入源
- 「问大家」板块同样影响转化，需要主动维护

### 合规红线
- **好评返现属于违规行为**，平台会处罚，且涉嫌违反《反不正当竞争法》
- **刷单炒信违法**，情节严重可构成犯罪
- 不得**删除或屏蔽真实差评**
