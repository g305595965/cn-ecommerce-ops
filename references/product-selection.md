# 选品方法论与决策框架

> 选品决定了 70% 的结果。运营能力只能放大选品的正确性，无法逆转错误的选品。

---

## 一、选品的四道门槛（顺序不可颠倒）

任何一款产品，必须按顺序通过以下四关，前一关不过直接淘汰，不要留恋。

### 第一关：合规关（一票否决）
先确认能不能卖，再谈赚不赚钱。

| 品类 | 强制要求 |
|------|---------|
| 3C 电子、儿童玩具、电器 | CCC 强制认证 |
| 食品 | 食品经营许可证、SC 生产许可 |
| 化妆品 | 化妆品备案凭证；美白/祛斑需「国妆特字」批文 |
| 保健食品 | 蓝帽子批准文号 |
| 医疗器械 | 一/二/三类医疗器械经营备案或许可 |
| 图书音像 | 出版物经营许可证 |
| 品牌商品 | 品牌授权书（缺失即侵权下架） |

**知识产权排查**：外观专利、实用新型专利、商标、著作权。
跨境或新奇特产品尤其容易踩专利雷，一封投诉信可能导致全店冻结。

### 第二关：利润关
用 `scripts/pricing.py` 实算，不要凭感觉。

**判断标准（经验值）**：
- 毛利率 **< 40%** —— 无法承担付费流量，只能靠自然流量，慎入
- 毛利率 **40%–60%** —— 可做，但投放空间紧张，需精细化运营
- 毛利率 **> 60%** —— 有充足投放空间，可以打爆款

**必须算进去但最容易被忽略的成本**：
去程运费、退货回程运费、包材、平台佣金、支付手续费、
推广费、客服人力分摊、仓储分摊、坏账与损耗。

### 第三关：需求关
判断这个东西**到底有没有人要**。

- **搜索型平台（淘宝/京东/拼多多）**：看关键词搜索指数与趋势。
  搜索量持续下滑的品类不要进，那是在接盘。
- **推荐型平台（抖音/小红书）**：看话题热度、同类内容互动量。
  已经有内容跑出爆款说明需求被验证，完全没有内容的要警惕是伪需求。
- **季节性判断**：提前 45–60 天布局。夏季品五月才上架已经晚了。

### 第四关：竞争关
```
供需比 = 关键词搜索人气 ÷ 在售商品数
```
供需比越高说明需求大而供给少，机会越大。

**竞争格局判断**：
- 头部（TOP10）占据 80% 以上份额 → 垄断市场，新手勿入
- 头部分散，长尾商家有销量 → 有机会切入
- 全是白牌低价厮杀 → 除非有供应链成本优势，否则不进

## 二、选品评分模型

用 `scripts/product_score.py` 量化打分，避免拍脑袋决策。
六个维度，加权总分 100 分：

| 维度 | 权重 | 评分要点 |
|------|-----|---------|
| 利润空间 | 25% | 毛利率高低，是否支撑投放 |
| 市场需求 | 20% | 搜索量/内容热度及趋势方向 |
| 竞争强度 | 20% | 供需比、头部集中度 |
| 退货风险 | 15% | 品类退货率、尺码/色差问题 |
| 物流成本 | 10% | 重量体积、易碎性、发货难度 |
| 供应链 | 10% | 起订量、翻单速度、账期 |

**决策阈值（经验值）**：
- **≥ 75 分** —— 优质款，可重点投入资源打造
- **60–74 分** —— 可做款，小批量测试后再决定
- **< 60 分** —— 放弃，机会成本太高

## 三、按退货率划分的品类风险

退货率是国内电商最容易被低估的利润杀手，尤其在抖音等冲动消费场景。

| 品类 | 退货率参考区间（经验值） | 主要原因 |
|------|----------------------|---------|
| 服饰鞋帽 | 30%–50%（直播可达 60%+） | 尺码、色差、版型预期落差 |
| 美妆护肤 | 10%–20% | 肤感不符、过敏 |
| 3C 数码 | 5%–15% | 参数不符、质量问题 |
| 家居日用 | 10%–20% | 尺寸不符、材质预期 |
| 食品生鲜 | 5%–15% | 物流损耗、口味 |
| 图书文具 | 3%–8% | 相对最低 |

**关键**：服饰类在抖音直播场景退货率可能超过 50%，
用 `pricing.py --return-rate 50` 算一下，很多"爆单"其实是巨亏。

## 四、产品结构：四种角色缺一不可

单靠一款产品无法支撑店铺，必须搭建产品矩阵。

1. **引流款**（占比 20%）
   低价高需求，用于获取流量与新客，毛利可接近于零，甚至微亏。
   考核指标是**引流效率**（UV 成本），不是利润。

2. **利润款**（占比 30%）
   店铺的现金流来源，毛利率 60% 以上，靠引流款带来的流量承接转化。
   考核指标是**利润额**。

3. **形象款**（占比 10%）
   高客单、高品质，拉高店铺整体调性与客单价，销量不高但不可缺。
   考核指标是**客单价拉升**。

4. **狙击款**（占比 40%）
   对标竞品的同款或改良款，用于抢占竞品流量，价格与卖点针对性设计。
   考核指标是**市场份额**。

## 五、供应链与备货

### 供应商评估要点
- **起订量（MOQ）** —— 首单不要压太多货，测款期用小单快反
- **翻单速度** —— 爆款出现后能否 7 天内补货，这决定能否吃到红利
- **账期** —— 现结还是月结，直接影响资金周转
- **质检能力** —— 次品率高会推高退货率，摧毁店铺权重
- **是否支持一件代发** —— 起步期降低库存风险

### 备货公式
```
安全库存 = 日均销量 × 补货周期天数 × (1 + 安全系数)
建议备货量 = 预估日销 × 备货天数 - 现有库存 - 在途库存
```
安全系数一般取 **0.2–0.5**，大促期间取上限。

**备货铁律**：
- 新品测试期：只备**7–15 天**销量，宁可断货也不要压死资金
- 稳定期：备**20–30 天**销量
- 大促前：按预估峰值备货，但要留好尾货处理方案
- **季节性商品必须在季末前清空**，压到下一年的库存基本等于亏损

## 六、常见选品陷阱

1. **自嗨式选品** —— "我觉得这个好"。市场数据才是唯一依据。
2. **只看销量不看利润** —— 卖爆了却在亏钱，是最常见的死法。
3. **忽略退货率** —— 服饰类尤其致命，退货率算错一切归零。
4. **忽略专利与授权** —— 尤其是新奇特产品与品牌周边。
5. **盲目跟风爆款** —— 你看到爆款时，红利期通常已过，
   且价格战已经开始，此时入场是接盘。
6. **供应链没谈好就推爆款** —— 推爆了补不上货，权重掉光，得不偿失。
